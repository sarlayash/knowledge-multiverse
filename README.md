## 🪐 The 25-Level Multiverse Curriculum

### 🌍 Domain 1: Foundations
- **Level 1 — Digital Foundations**: Binary, Data Representation, IT in daily life.
- **Level 2 — Computer Fundamentals**: CPU Cycles, RAM vs SSD, Motherboard & Hardware Anatomy.
- **Level 3 — Computer Organization**: Fetch-Decode-Execute Cycle, Pipelining, RISC vs CISC, DMA.

### 💻 Domain 2: Systems & Low-Level
- **Level 4 — Operating Systems**: Process vs Thread, Scheduling (FCFS, SJF, RR), Paging, Coffman Deadlocks.
- **Level 5 — C Programming**: Variables, Loops, Functions, Pointers, Structs, Dynamic Memory (`malloc`/`free`), File I/O.

### 🗄️ Domain 3: Data & Web Systems
- **Level 6 — Database Management**: Relational Algebra, SQL DDL/DML, 3NF Normalization, ACID, Indexes.
- **Level 7 — Web Development**: Semantic HTML5, CSS Grid & Flexbox, Modern JavaScript ES6+, DOM, REST APIs.

### ⚙️ Domain 4: Software Engineering & Agile
- **Level 8 — MS Office & Productivity**: Spreadsheets, XLOOKUP, Pivot Tables, Executive documentation.
- **Level 9 — SDLC**: Waterfall, V-Model, Software Quality Assurance, Defect Escalation economics.
- **Level 10 — Project Life Cycle**: Initiation, Work Breakdown Structure (WBS), Critical Path Method (CPM).
- **Level 11 — Agile & Scrum**: Agile Manifesto, Scrum Ceremonies, User Stories, Fibonacci Velocity estimation.
- **Level 12 — DevOps & CI/CD**: GitFlow & Trunk-based dev, Automated Pipelines, Canary releases, Observability.

### ☁️ Domain 5: Enterprise, Infrastructure & Cloud
- **Level 13 — IT Industry & Roles**: Developer, DevOps, SRE, Data Engineer, Cloud Architect, IC vs Manager tracks.
- **Level 14 — IT Infrastructure & Services**: Datacenters, SAN/NAS, RAID (RAID 0, 1, 5, 10), Active Directory.
- **Level 15 — Computer Networking**: OSI 7-Layer Model, TCP vs UDP, IPv4 Subnetting, Routing & Switching.
- **Level 16 — Virtualization**: Type 1 vs Type 2 Hypervisors, Docker Containers vs VMs, Linux cgroups & namespaces.
- **Level 17 — Cloud Computing**: IaaS/PaaS/SaaS, Multi-AZ High Availability, AWS/GCP architecture, FinOps.
- **Level 18 — Information Security**: CIA Triad, Cryptography (AES, RSA, Hashing), OWASP Top 10 vulnerabilities.

### 🚀 Domain 6: AI & Frontier Technologies
- **Level 19 — Industry 5.0**: Human-centric collaboration, Cobots, Digital Twins, Predictive Maintenance.
- **Level 20 — AI & Machine Learning**: Supervised/Unsupervised, Neural Networks, Backpropagation, F1 Score.
- **Level 21 — Generative AI & ChatGPT**: Transformers, Self-Attention, Prompt Engineering, RAG & AI Agents.
- **Level 22 — Blockchain & Web3**: Distributed Ledgers, Cryptographic Hash chains, Proof of Work, Smart Contracts.
- **Level 23 — Internet of Things (IoT)**: Microcontrollers (ESP32/RPi), Sensor telemetry, MQTT Pub/Sub protocols.
- **Level 24 — AR / VR / MR + Drones**: 6 DoF Spatial Computing, SLAM algorithms, Drone PID stabilization.
- **Level 25 — 3D Printing & Emerging Tech**: Additive Manufacturing, G-Code, Quantum Computing Superposition.

## 🛠️ Key Platform Features

1. **Hands-On Live Browser IDE**:
   - Write, run, and debug **C, C++, Java, Python, JavaScript, and SQL** directly in the browser.
   - Built-in **Test Case Runner**: Displays Input, Expected Output, Actual Output, and Pass/Fail verification (`3 / 5 Test Cases Passed`).

2. **7 Interactive IT Industry Simulations**:
   - 🏢 **IT Support**: Investigate APIPA auto-IP assignment, renew DHCP lease, and flush DNS cache.
   - 🌐 **Networking**: Diagnose multi-hop routing, detect firewall packet drops, and permit TCP 443 ACL rules.
   - 🗄️ **Database**: Formulate complex SQL multi-table joins on real business schemas.
   - 💻 **Software Developer**: Hunt off-by-one errors and array bounds crashes in production code.
   - ☁️ **Cloud Engineer**: Deploy high-availability infrastructure with ALBs and Multi-AZ Aurora DB.
   - 🔐 **Security**: Exploit SQL injection flaws in sandbox, apply parameterized query patches, and enforce rate limits.
   - 🚀 **DevOps**: Troubleshoot Docker builds and execute zero-downtime canary deployments.

3. **10+ Practical Portfolio Projects**:
   - Accumulate 10+ guided projects with blueprints and starter templates into a shareable portfolio.

4. **Placement Readiness Center & 15-Dimension Meter**:
   - Evidence-based score derived directly from passed tests and challenges:
     `FOUNDATION` → `DEVELOPING` → `PRACTICE READY` → `INTERVIEW READY` → `INDUSTRY READY`.
   - Includes **FAANG Interview Q&A Bank** and **ATS Resume Audit Checklist**.

5. **Mock Assessment Center (5 Modes)**:
   - Topic Mock, Level Mock, Domain Mock, Placement Mock, and Grand Multiverse Mock.
   - 5-minute live countdown timer, randomized questions, scorecards, accuracy metrics, and identified weak areas.

6. **11 Collectible Celestial Badges & Verifiable QR Certificates**:
   - Dynamic SVG QR code generator, Unique Certificate ID, printable PDF format, and online verification page.

7. **Adaptive Learning Intelligence**:
   - Automatically detects error patterns (`⚠️ KNOWLEDGE GAP DETECTED: You may want to revisit SQL JOINs`) and generates immediate 4-step remediation drills.

## 📦 Local Installation & Development

```bash
# Clone the repository
git clone https://github.com/sarlayash/knowledge-multiverse.git

# Navigate to project directory
cd knowledge-multiverse

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 📱 Mobile & PWA Installation
1. Open the application in Safari (iOS) or Chrome (Android).
2. Tap **Share / Menu** (`⋮` or Share icon).
3. Select **"Add to Home Screen"**.
4. Launch full-screen with offline support!
